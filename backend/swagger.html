📚 Smart Recruitment System API

Hệ thống tuyển dụng thông minh - Tài liệu API đầy đủ

📋 Tổng quan hệ thống

🔐 Xác thực

Sử dụng JWT token với Bearer authentication. Token được refresh qua endpoint /auth/refresh.

👥 Vai trò người dùng

Candidate: Ứng viên tìm việc
Recruiter: Nhà tuyển dụng
Admin: Quản trị viên

🌐 Base URL

Development: http://localhost:8000/api
Production: https://api.srs.com/api

🔑 Mẫu request với token

// JavaScript - Fetch API
fetch('http://localhost:8000/api/auth/me', {
    method: 'GET',
    headers: {
        'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIs...',
        'Content-Type': 'application/json'
    }
});

// cURL
curl -X GET "http://localhost:8000/api/auth/me" \
     -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
     -H "Content-Type: application/json"

🚀 Các chức năng chính

  • POST /auth/register/candidate - Đăng ký ứng viên
  • POST /auth/register/recruiter - Đăng ký nhà tuyển dụng
  • POST /auth/login - Đăng nhập hệ thống
  • GET /jobs - Tìm kiếm công việc
  • POST /applications - Nộp đơn ứng tuyển
  • POST /interviews - Lên lịch phỏng vấn
  • GET /recommendations/jobs - Đề xuất công việc
